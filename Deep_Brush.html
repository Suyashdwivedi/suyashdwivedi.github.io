When enabled, the entire image/logo rectangle gets a solid background. This removes transparent holes so the photograph cannot show through the design. Warp uses the current depth map. Run AI depth before increasing this control; the built-in brightness estimate is only a fallback and cannot model complex cloth folds. 0 = preserve the design's shape. Higher values add only a slight depth-based bend.

Choose Select / move designs, then drag an object. Drag an item to move it, resize it with its corner handle, rotate it with Angle, and adjust Surface wrap to make it follow the photo.
