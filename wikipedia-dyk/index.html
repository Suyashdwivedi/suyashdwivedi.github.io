Wiki DYK Share Tool

Turn a fact from any Wikipedia or Wikimedia page into a shareable image with a QR code

1. Load an article

Paste a link from any Wikipedia language or Wikimedia project, or a w.wiki short link. Add a #section to start there.

Select text to use it as your fact. Click an image to use it as the background.

3. Choose a background image

Images found on the page appear here.

Position the photo

Slide the photo to keep the important part in the frame. With a mouse you can also drag the preview.

4. Pick a format

Text position
QR code position

If you paste a w.wiki short link, the QR code uses it (smaller and easier to scan) while the image shows the full link.

Image format

Your image preview appears here.

WhatsApp, Instagram and X only take the image from a share, so they leave the caption out. Share image + caption copies the caption first, so after you pick the app, paste it into the caption field. On desktop, use Copy image, paste it in the chat, then Copy caption.
